# 双图集地图生成流程

在仓库根目录运行 `node server/dev-server.mjs`，打开 `http://127.0.0.1:5173`。

1. 选择地貌并填写素材风格。配置生图接口后点击“一键生成两张图集”（调用两次接口），或分别生成地砖与前景。可独立重试、上传两张图；“演示双图集”无需接口。
2. 地砖图集为 **4 列 × 4 行**：每行一种地形，每列一种变化。前景为 **4 列 × 2 行**，单格一个完整物件，纯品红背景。页面清单给出每个格子的素材名称。
3. 显示切分线检查排列，点击“提取图集素材”。地砖边长决定输出尺寸；图集有分隔线时调整向内裁切比例，前景边缘有底色时调整抠图容差。支持已有透明通道的前景。
4. 默认根据提示词中的“湖泊”“河流”“无水”等关键词选布局，也可指定河流、湖泊或开阔布局。设置地图大小并拼图，同样素材、种子、尺寸和参数会得到相同结果。后续可用画笔、物件、阻挡与撤销微调，并导出 PNG、V100 地图、素材图集或工程。

替换图集或重新提取会清空旧地图和历史；需要保留的地图请先导出工程。工程包含两张源图、素材和物件尺寸，重新打开后可继续提取、拼图或编辑。两张源图较大时，本地草稿可能超过浏览器配额，使用“导出工程”保存。

生图模型可能偏离规则网格；本地提取不识别任意散排的物件。独立图集预览、单图重试和裁切设置可用于校正。

## 验证

- `node --test server/ai-image.test.mjs server/atlas.test.mjs`：图片响应解析、图集清单、拼图确定性与保存恢复。
- 先启动开发服务，再运行 `node server/e2e-smoke.mjs`（或 `python server/atlas-smoke.py`）：浏览器全流程、透明像素、绘制撤销/重做、导出与失败重试。需要 Python Playwright 及其 Chromium；可用 `PYTHON` / `CHROME` 环境变量指定程序，截图写入 `output/atlas-review/`。
