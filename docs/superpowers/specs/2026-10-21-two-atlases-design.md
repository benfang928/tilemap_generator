# 两张素材图集流程

用户已确认使用两张图集：地砖图集与前景图集。主流程改为生成图集、规则提取、程序化拼图和手动编辑。旧工程仍可打开编辑。

- 地砖图集固定 4 列 × 4 行，每行一种地形，每列一种变化；地貌决定行的名称及碰撞类型。前景图集固定 4 列 × 2 行，每格一个完整物件，使用纯品红背景与安全边距。
- 两张图共享提示词、美术风格和地貌。分别调用现有生图接口；每张图独立保存、重试、上传与预览，第二张失败时保留第一张。
- 按整数网格边界切片，地砖使用完整单元格并可调整边距；前景使用可调背景阈值抠图、透明裁边，保留实际宽高比。素材类型来自图集清单，用户仍可在素材库修改。
- 拼图使用种子、地貌、提示词中的地形偏好生成连贯区域和道路，随后放置前景、封边和清理孤岛；不把图集当成地图布局，也不再调用视觉识别。
- 保存图集原图、清单、生成参数和物件尺寸，重新加载后可再次提取和拼图。替换图集会清空旧地图索引和编辑历史，避免索引对应错误。
- 提供不调用 API 的双图集演示。验证规则网格、抠图、相同种子结果、类型与碰撞、部分生成失败保留、工程往返以及完整浏览器流程。

限制：生成模型可能不严格遵守网格，页面展示切分线并提供单图重试、上传和边距调整；固定网格不承诺任意散排素材均可正确提取。
