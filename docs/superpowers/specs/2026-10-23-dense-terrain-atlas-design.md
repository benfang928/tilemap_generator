# 可配置地砖图集与方向过渡素材

用户要求同时改善地图岩壁封边和草地/水/道路过渡，并按指定地砖大小扩大图集容量。1024×1024、96 像素槽位必须容纳 10×10 共 100 格。

## 方案

采用同一张图集内的基础纹理与方向过渡素材清单。仅增加平面变体不能改善崖面；固定生成全部 3×47 状态又无法装入 100 格。因此按容量优先分配常见方向状态，缺少状态由确定性程序形状补齐。

- 新布局使用 `floor(sheetSize / slotSize)` 列/行，正方形槽位按整数像素居中排布，余量作为外围留边。1024/96 是 960×960 内容区与四周 32 像素留边。槽位内仍使用中心 3:2 有效区域，96 槽位对应 96×64 可用素材；游戏逻辑格保持 48×32。
- 默认 1024、96。允许设置 32–512 像素槽位及现有图集尺寸；保留旧版 4×4 选项以导入旧图集。保存布局版本、尺寸与裁切区域，预览网格、提示词、演示、提取共享清单。
- 约 40% 格子分配给四类基础材质，其余优先分配岩壁、岸线、路缘三组过渡，按 N/NE/E/SE/S/SW/W/NW 八邻域编码。对角仅在相邻两条直边都连接时有效，共 47 个规范状态；全连接状态用基础素材，因此每组最多 46 个方向状态。100 格为 40 基础、60 过渡，每组 20 种。
- 优先常见直边、外角、端头、独立块、窄线与单个内角，再按稳定次序补其他状态。清单和提示词写明每格材质、邻接方向、背景为本地貌 floor，不允许自由散排、任意旋转、文字、悬浮立体砖。岩壁在正确朝向绘制崖面，岸线含水陆接触，道路含路缘，使用一致尺度与光向。
- 自动布局只选基础素材作为语义格；渲染按实际邻域选择过渡帧。只有与 floor 相接的单一材质区域使用预画过渡；缺少方向帧时按同一规范状态生成遮罩。三材质交会沿用分层合成，但公共边与顶点使用共享拓扑采样，避免与预画形状断开；原生 48×32 输出的最外一圈像素统一为相同边界规范。旧项目保持原遮罩算法。提取时基础纹理校边与方向帧校边分开，避免覆盖过渡形状。
- 提取、工程 JSON、素材图集 JSON 保存 role、mask、backgroundKind 与槽位信息。PNG 和 Lib 继续共用地面渲染结果。
- 修改生成设置不重新解释已有图集；新生成/上传才使用新清单。替换地砖布局保留同主题前景，但会清空旧地图；只重试前景保留已有地砖清单。

## 验证

Node 验证容量、47 状态、优先常见状态、提示词及旧布局兼容，排除方向素材参与随机铺地，核对提取坐标与元数据往返。浏览器验证默认 100 格、尺寸修改、旧图集切换、保存恢复、生成请求清单、方向帧实际选用与形状回退，继续运行已有中心/接缝及 Lib 重建验证。使用演示和模拟接口，不调用付费生图。

真实 AI 对 100 格严格排版及接缝的遵循程度仍需真实素材验收；本轮保证生成约束、消费规则与可复现的演示流程。
