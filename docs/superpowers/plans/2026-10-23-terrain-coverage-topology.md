# 保留单格地形与窄带的过渡遮罩修复计划

**目标：** 修复孤立水格消失、单格宽水带或道路无完整内部的问题，保持公共接缝一致。

**依据：** `2026-10-23-tiled-stitching-research.md` 中复现的四角平均覆盖问题，以及用户继续推进拼接优化的指令。

**方案：** 在现有 48×32 格中使用 3×3 覆盖采样网格：四角仍由共享顶点处四个语义格平均；边中点由相邻两个语义格平均；中心直接采用当前格的语义占用值。将格子分为四个区域分别插值，再用原有平滑阈值转为透明度。公共边上的三个控制值由两边共同决定，因此拼接一致；中心与同类连通边可达到完全不透明。

相比调低原有阈值，本方案同时保留空洞中心和窄带中心；相比完整引入 47 状态资源，改动集中在当前遮罩与其调用方。它不是完整的 blob 状态系统，不处理立体岸壁、城墙和显式方向图块。

**文件：**

- `web/js/terrain.js`：用 `coverageGrid` 返回九个行优先采样值，并修改 `sampleCoverage` 在子区域中插值。
- `web/js/render.js`：使用新的覆盖网格；网页与 PNG 保持共用 `terrainImage`。
- `server/terrain.test.mjs`：单格、水平/竖直窄带、内部空洞、局部编辑及全组合接缝测试。
- `server/atlas-smoke.py`：增加真实 Canvas 像素夹具，检查中心、连接处、相邻边及 PNG 渲染结果，输出对照图。
- `docs/superpowers/specs/2026-10-23-tiled-stitching-research.md`：记录修复范围与验证结果。
